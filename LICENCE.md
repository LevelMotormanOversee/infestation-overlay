### 🎮 Core Features
- ESP — see players, zombies, and loot through walls
- Radar — minimap with real-time entity positions
- Item Filter — highlight specific items and loot
- Stats Tracker — track kills, deaths, and survival time
- Customizable Menu — toggle features on the fly

- Player Names — display names above players
- Distance Indicators — show distance to entities
